# 📊 Data Cleaning & Preparation
Practical data cleaning workflow with Python. Covers dataset inspection, missing value treatment, duplicate removal, column standardization, numeric conversion, and reshaping for analysis. Internship submission and GitHub showcase.
## 🔍 Project Overview
This project demonstrates how to clean and prepare a dataset (Coca Cola financial data) using Python libraries (pandas, NumPy).
## 🛠️ Steps Performed
1. Import libraries  
2. Load dataset  
3. Inspect data (shape, info, head, describe)  
4. Handle missing values  
5. Remove duplicates  
6. Standardize column names  
7. Convert numbers to numeric  
8. Reshape dataset (wide → long)  
9. Validate cleaned dataset  
## 💻 Technologies Used
- Python (pandas, NumPy)
- Google Colab
- GitHub
## 📊 Results
- Cleaned dataset ready for analysis
- Internship submission deliverables prepared
## 🎯 Conclusion
This project highlights the importance of systematic data cleaning for accurate analysis.
